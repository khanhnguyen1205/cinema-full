# PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Biến cinema-full thành PWA cài đặt được — offline app-shell + cache catalog công khai, nút "Cài đặt ứng dụng" riêng, toast nhắc cập nhật — không đổi hợp đồng API, không cache dữ liệu cá nhân.

**Architecture:** Thêm `vite-plugin-pwa` (Workbox generateSW) cấu hình trong `vite.config.mjs`: precache shell + runtime-cache **chỉ** catalog GET công khai (SWR). React nhận SW qua `virtual:pwa-register/react` (toast cập nhật) + hook `useInstallPrompt` bắt `beforeinstallprompt` (nút cài đặt). Icon dựng 1 lần bằng headless Chrome (Playwright) từ SVG, commit PNG vào `public/`. Prod: Express đã serve `build/` nên `sw.js`/`manifest.webmanifest` phục vụ ở gốc — backend 0 đổi.

**Tech Stack:** Vite 6, vite-plugin-pwa 1.3.0 (Workbox 7), React 18 + TypeScript, react-i18next, @fontsource/bebas-neue, Playwright (dựng icon).

## Global Constraints

- **KHÔNG bật `devOptions.enabled`** — SW phải tắt trong `npm run dev` để Playwright e2e không bị cache /api can thiệp.
- **Runtime cache CHỈ** catalog công khai: `/api/{movies,showtimes,cinemas,cities,rooms,concessions,reviews}`. Tuyệt đối KHÔNG cache `/api/bookings`, `/api/users`, `/api/occupied-seats`, `/api/holds`, `/auth/*`.
- Mọi chuỗi hiển thị qua `t("pwa.*")`; thêm key vào **cả** `vi.json` và `en.json`.
- Giữ 6 cổng CI xanh mỗi commit (typecheck · lint 0-warning · format:check · test:run · e2e · build), push thẳng `main`.
- Prettier printWidth 80, double-quote, semi, trailingComma all. `format:check` quét cả `scripts/**` và `.mjs` — file mới phải prettier-clean.
- vite-plugin-pwa **pin `1.3.0`** (không nhảy major sau này).
- `theme_color`/`background_color` = `#0a0a0a` (khớp meta có sẵn). `--red` = `#e63030`.

- [ ] **Step 5: Viết `src/hooks/useInstallPrompt.ts`** (store cấp module + `useSyncExternalStore` để nhiều instance đồng bộ)

```ts
import { useSyncExternalStore, useCallback } from "react";

type BeforeInstallPromptEvent = Event & {
  prompt: () => Promise<void>;
  userChoice: Promise<{ outcome: "accepted" | "dismissed" }>;
};

let deferred: BeforeInstallPromptEvent | null = null;
const listeners = new Set<() => void>();
const emit = () => listeners.forEach((l) => l());

if (typeof window !== "undefined") {
  window.addEventListener("beforeinstallprompt", (e) => {
    e.preventDefault();
    deferred = e as BeforeInstallPromptEvent;
    emit();
  });
  window.addEventListener("appinstalled", () => {
    deferred = null;
    emit();
  });
}

const subscribe = (cb: () => void) => {
  listeners.add(cb);
  return () => {
    listeners.delete(cb);
  };
};
const getSnapshot = () => deferred;

export function useInstallPrompt() {
  const evt = useSyncExternalStore(subscribe, getSnapshot, () => null);
  const promptInstall = useCallback(async () => {
    if (!deferred) return;
    await deferred.prompt();
    deferred = null;
    emit();
  }, []);
  return { canInstall: evt !== null, promptInstall };
}
```
